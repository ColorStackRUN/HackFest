# HackFest 2026 Website

**Theme: Building Newark.** Students building tech that builds up the city.
Hosted by GWC x CSRUN at Rutgers–Newark.

## What's in here

```
hackfest-2026-website/
├── index.html          ← the page (all the text lives here)
├── css/
│   ├── tokens.css      ← brand colors + fonts (from the Design Language sheet)
│   └── styles.css      ← layout and components
├── assets/
│   └── images/         ← put logos and photos here
├── DESIGN.md           ← design rules for anyone editing the site
└── README.md           ← this file
```

## See it on your computer

Double-click `index.html`. It opens in your browser. No install needed.

## Making changes

1. Change text in `index.html`.
2. Change a brand color or font in `css/tokens.css` only. Every other file reads from there.
3. Check `DESIGN.md` before adding anything new.
4. Commit with a short message that says what changed, e.g. `Add sponsor logos`.
